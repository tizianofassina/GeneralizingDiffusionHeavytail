## What is this?

Score-based generative models (SGMs, i.e. diffusion) are state of the art on high-dimensional data, but
**extending them to heavy-tailed targets is an open problem**: the standard construction starts the reverse
process from a Gaussian at a very large noise level, an assumption that is fundamentally mismatched with
heavy tails. This repository is the official code for the paper *Generalizing Score-based Generative Models
for Heavy-tailed Distributions*, which extends the diffusion framework to **any target distribution** by
decoupling two ingredients: **a flexible initialization** of the reverse process and **early stopping**.

The code is organized in two self-contained parts:

- **`toy_data_experiments/`** — controlled 2D experiments (a heavy-tailed Student-*t* mixture and a Gaussian
  mixture) that isolate and measure the effect of the initialization, with both a learned neural denoiser and
  three MCMC-based denoisers.
- **`real_data_experiments/`** — high-dimensional validation on images (FFHQ-64 faces and two ImageNet-512
  subsets, birds and dogs), where a lightweight **TarFlow** normalizing flow is trained on *noised* data and
  used as the initialization for a pretrained **Karras EDM / EDM2** denoiser.

> 📄 **Paper:** *Generalizing Score-based Generative Models for Heavy-tailed Distributions* — preprint
> [`arXiv:2603.00772`](https://arxiv.org/abs/2603.00772), under review. See [Citation](#citation).

## The idea in one minute

The standard diffusion sampler starts from a Gaussian prior $\pi_\infty \sim \mathcal{N}(0,\sigma_{\max}^2 I)$
at $\sigma_{\max}=80$ and denoises over the full horizon. Two observations change this:

1. **A Gaussian is a bad approximation of the noised distribution when the target is heavy-tailed.** At any
   finite time the noised distribution $\vec p_T$ stays heavy-tailed, while the Gaussian is light-tailed, so
   the classic initialization mismatches the true starting distribution in exactly the region that matters —
   the tail.
2. **Early stopping helps.** Convolving any distribution with a bit of Gaussian noise makes it smooth and,
   eventually, unimodal — a regime where a normalizing flow can learn it reliably.

This yields a **two-stage pipeline**: a normalizing flow captures the *noised* distribution $\vec p_T$ and
provides the initialization $p_0^\theta$; a **short-horizon, early-stopped** diffusion denoiser then refines
the fine-scale structure. The flow supplies the tails; the denoiser supplies the details. The horizon
$\sigma_T$ is chosen small enough that $\vec p_T$ is near the data yet large enough that it is unimodal
(located with a dip test). The flow can be trained in two regimes — **fixed noise** (a noised dataset drawn
once) or **dynamic noise** (fresh noise every epoch, a regularizing, data-augmentation-like scheme).

Every experiment compares the same set of [initialization strategies](#initialization-strategies): the naive
Gaussian $\pi_\infty$, the true noised distribution $\tilde p_T$, and the learned flow $p_0^\theta$.

## Requirements

Each experiment was developed on an HPC cluster and **ships its own `requirements.txt`** — the toy code is
JAX-based, the image code is PyTorch-based, and the three image sub-projects with different requirements (CUDA versions differ among different architectures). Set up
one environment per part you intend to run; minor adjustments may be needed on local hardware.

| Part | Libraries | Requirements |
| --- | --- | --- |
| `toy_data_experiments/` | JAX · flowjax · equinox · optax · numpyro · blackjax · torch · Lightning · diptest | `toy_data_experiments/requirements.txt` (`pip install -e .` installs `src/` as `hf_toy`) |
| `NoisedFlow/` | PyTorch · Lightning (TarFlow training) | `real_data_experiments/NoisedFlow/requirements.txt` |
| `FFHQ_diffusion/` | PyTorch (EDM / Karras pipeline) | `real_data_experiments/FFHQ_diffusion/requirements.txt` |
| `ImageNet_diffusion/` | PyTorch · diffusers · xformers (EDM2 / Karras pipeline) | `real_data_experiments/ImageNet_diffusion/requirements.txt` |

Pretrained weights are **not** included: the EDM / EDM2 denoisers (from NVIDIA), the Stability VAE (ImageNet
latent decoding), and the DINOv2 / Inception feature extractors (metrics) must be downloaded and placed in the
`model_weights/` folders as described in each sub-README.

## The repository, file by file

Two independent trees. The toy side is a JAX playground; the real-data side is a PyTorch pipeline built around
pretrained Karras denoisers.

```
Code_for_paper/
├── toy_data_experiments/      # Section 4 — synthetic 2D targets (GMM + Heavy-Tailed)
└── real_data_experiments/     # Appendix — high-dimensional images
    ├── NoisedFlow/            #   (1) train a TarFlow on NOISED data  → the p_0^θ initialization
    ├── FFHQ_diffusion/        #   (2) EDM denoiser (Karras 2022) on FFHQ-64
    └── ImageNet_diffusion/    #   (3) EDM2 denoiser (Karras 2024) on ImageNet birds & dogs
```

### `toy_data_experiments/` — synthetic 2D (GMM + Heavy-Tailed)

Controlled experiments in $d=2$ comparing denoising from the three initializations. Two parallel setups: a
**heavy-tailed** 4-component multivariate Student-*t* mixture (df=3), where the score is approximated by a
neural denoiser and by MCMC; and a **25-mode Gaussian mixture** (GMM), where the score is analytic, plus an
extra Monte-Carlo KL evaluation.

| File | What it does |
| --- | --- |
| `create_train_test_data_ht.py` | Builds the heavy-tailed target; writes train sets of size 10³/10⁴/10⁵ and two 10⁷ test sets (seeds hard-coded). |
| `gen_flow_ht.py` | Trains the heavy-tailed flow (Student-*t* base) over a `(sigma, n_train)` grid and samples `p_theta`. Arg: `dynamic` \| `fix`. |
| `gen_init_ht.py` | Generates the `p_inf` (Gaussian) and `p_t` (true noised) initializations at the three σ values. |
| `diffusion_generation_nn.py` | Trains the neural denoiser (one per train size) and runs DDPM sampling for every `(train_size, sigma, init)`. |
| `diffusion_generation_mcmc.py` (+`.sh`) | DDPM sampling with the MCMC denoisers (`hmc`/`barker`/`nuts`); parametrized for a Slurm array. |
| `results_ht.py` | Evaluation: bulk Max-Sliced Wasserstein + tail quantiles along a worst-case direction; one CSV. |
| `evaluating_mcmc.py` | Assesses the quality of each MCMC posterior estimate against an oracle. |
| `create_train_test_data_gmm.py` | Builds the 25-mode GMM target; same sizes/seeds as the HT side. |
| `gen_flow_gmm.py` | Trains the GMM flow (Gaussian base) and samples `p_theta`. Arg: `dynamic` \| `fix`. |
| `diffusion_generation_gmm.py` | DDPM sampling with the **analytic** GMM-convolved score for every `(sigma, init)`. |
| `results_gmm.py` | Global MSW + Monte-Carlo `KL(p_t‖p_theta)` over the full `(n_train, sigma)` grid; two CSVs. Arg: `dynamic` \| `fix`. |
| `config_diffusion.yaml` | Hyperparameters of the neural denoiser (EDM-preconditioned MLP) and DDPM sampling. |
| `pyproject.toml` | Installs `src/` as the `hf_toy` package. |
| **`src/bulk_metrics.py`** | Max-Sliced Wasserstein distance (gradient-based worst-direction search). |
| **`src/create_data.py`** | The heavy-tailed reference distribution (Student-*t* mixture). |
| **`src/create_data_gmm.py`** | The Gaussian-mixture reference distribution. |
| **`src/diffusion_samplers.py`** | DDPM sampling loops. |
| **`src/mc_denoisers.py`** | HMC / Barker / NUTS posterior-mean denoisers (numpyro / blackjax). |
| **`src/find_unimodality.py`** | Hartigan dip-test analysis that locates the unimodality-onset horizon `σ_T`. |

> Run order (HT): `create_train_test_data_ht` → `gen_flow_ht` → `gen_init_ht` → `diffusion_generation_nn` →
> `diffusion_generation_mcmc` → `results_ht`. GMM: `create_train_test_data_gmm` → `gen_flow_gmm` →
> `diffusion_generation_gmm` → `results_gmm`. Steps are fail-loud; skipping one makes the next crash by design.
> The HT neural-denoiser step additionally needs the `VE_SGM` diffusion package on `PYTHONPATH`.

### `real_data_experiments/ImageNet_diffusion/` — EDM2 denoiser on ImageNet

Loads the pretrained **EDM2 (Karras et al., 2024) "S" latent denoiser** with classifier-free guidance,

them. Slurm-oriented; **birds** by default.

| File | What it does |
| --- | --- |
| `generate_data.py` | Main generation (arg: seed). Loads the EDM2 net + guidance `gnet`, sweeps the flow CFG scales `{0.5,1.0,1.5,2.0}` × {fixed, dynamic} plus `empirical`, `gaussian` (σ=7) and `edm_classic` (σ=80, 32 steps), 1000 images/class. |
| `generation/sampling.py` | EDM2 **Heun** sampler with classifier-free guidance, per-class latent generation, and `decode_dict_clean` (Stability VAE latent→RGB, with the NVIDIA latent de-normalization). |
| `generation/encoder.py` | Stability VAE encoding helpers (image → latent). |
| `generation/stability_encoder_decoder/config.json` | Local Stability VAE configuration. |
| `feats_real_data.py` | Precomputes FID / DINO features and statistics for the real training subset. |
| `compute_results_birds.py` / `compute_results_dogs.py` | Metrics (FID, KID, DINO-FD, FID, SWD, MaxSWD) for each subset. |
| `metric_fid_wass_class.py` | Metric implementations, including a classifier-based check. |
| `nearest_for_plot_birds.py` / `nearest_for_plot_dogs.py` | Nearest-neighbour grids for each subset. |
| `generation/dnnlib/`, `generation/torch_utils/` | Vendored EDM2 utilities. |
| `job_*.sh` | Slurm launchers — generation (A100), nearest-neighbour, and results (H100), per subset. |
| `generation/model_weights/` | Place the EDM2 conditional + `gnet` `.pkl` files here (download separately). |

## Initialization strategies

The whole study is a controlled comparison of **where the reverse diffusion starts**. Every experiment
evaluates the same strategies (the flow-based one being the method proposed in the paper):

| Strategy | Starting distribution | Horizon | Role |
| --- | --- | --- | --- |
| `π_∞ (σ=80)` | Gaussian $\mathcal{N}(0,\sigma_{\max}^2 I)$ | long — 40 (FFHQ) / 32 (ImageNet) steps | classic EDM baseline |
| `π_∞ (σ_T)` small | Gaussian at a small $\sigma_T$ (≈7, or the toy σ's) | short — 20 steps | *uninformed* short-horizon baseline |
| `p̃_T` (empirical) | real data + $\sigma_T$ noise | short | near-ideal oracle initialization |
| **`p_0^θ` (flow)** | **TarFlow / coupling flow trained on noised data** | short | **proposed method** — trained *fixed* or *dynamic*; CFG-guided on ImageNet |
| flow (clean data) | flow trained on clean data | — | toy-only baseline |

On the toy targets the denoiser is either the analytic score (GMM), a learned EDM-preconditioned MLP, or one
of three MCMC samplers (HMC / Barker / NUTS). On images the denoiser is a **frozen** pretrained Karras model —
only the flow is trained here.

## Metrics

| Setting | Metrics |
| --- | --- |
| Toy (2D) | bulk **Max-Sliced Wasserstein**, **tail quantiles** along a worst-case projection, Monte-Carlo **KL** (GMM), and MCMC-quality diagnostics. |
| Images | **FID**, **KID**, **DINO-FD** (DINOv2 Fréchet distance), **SWD** and **MaxSWD**; plus nearest-neighbour grids to confirm samples are not memorized. |

On ImageNet, SWD/MSW are computed in latent space and the rest in pixel space; image scores are reported as
the best of three independent generations and averaged over multiple projection draws, following the Karras
evaluation protocol.

## Datasets

- **Toy (synthetic, generated by the code).** A 2D **heavy-tailed** mixture (4 multivariate Student-*t*,
  df=3) and a 2D **Gaussian mixture** (25 modes). Produced by the `create_train_test_data_*` scripts.
- **FFHQ-64** (faces). Download per the [EDM instructions](https://github.com/NVlabs/edm); pack with
  `NoisedFlow/FFHQ_Flow/datasets/dataset_tool.py`.
- **ImageNet-512, birds & dogs subsets.** Obtain and VAE-encode per the
  [EDM2 instructions](https://github.com/NVlabs/edm2), reorder into per-class folders, and select the subset in
  `flow_class_map.json`.

## Reproducing the paper

The two parts map onto the paper as follows. All scripts fix random seeds for reproducibility.

| Paper | Code |
| --- | --- |
| Numerical illustration — GMM & Heavy-Tailed (Sec. 4) | `toy_data_experiments/` |
| The role of initialization (π_∞ vs p̃_T vs p_0^θ) | `gen_init_*`, `diffusion_generation_*`, `results_*` |
| Flow training: fixed vs dynamic noise | `gen_flow_*` (toy), `NoisedFlow/*/train_noised_lightning.py` (images) |
| Real-world validation — FFHQ-64, ImageNet birds/dogs (Appendix) | `real_data_experiments/{NoisedFlow, FFHQ_diffusion, ImageNet_diffusion}` |

A typical image run is: train the flow on noised data (`NoisedFlow`), generate the initialization tensors,
then generate + evaluate with the matching diffusion sub-project (`FFHQ_diffusion` or `ImageNet_diffusion`).
